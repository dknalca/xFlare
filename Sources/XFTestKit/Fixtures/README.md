# Fixtures

Recursos empaquetados con `XFTestKit` y disponibles para los tests via
`XFTestKit.fixturesURL`.

- `sessions/` — tomas `.xfsession` grabadas (tests de replay de `XFAnalysis`).
- `golden/` — SVG / JSON de referencia (golden tests de `XFNotation` y `XFRender`).
